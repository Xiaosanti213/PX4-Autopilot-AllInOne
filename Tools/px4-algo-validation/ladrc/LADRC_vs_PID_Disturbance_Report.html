对比分析

核心发现：LADRC 展现出了垂直轴优势

在扰动环境中，LADRC在高度控制(Z轴)上以780%的优势碾压PID（0.41m vs 3.63m RMS）。 EKF的高度测试比率也以254%的优势更优（0.03 vs 0.12）。 这直接证明了LADRC的ESO在估计并补偿垂直方向总扰动（重力+质量变化+推力衰减）方面确实有效。

然而，LADRC的角速率控制全面劣于PID（差97-99%），这是因为b0参数（控制效能系数）对roll/pitch轴的估计不准确。 角速率控制不准 → 姿态偏离 → 侧向漂移（X方向19m!）→ 位置跟踪崩溃。

关键趋势： 扰动越强，LADRC在高度控制上的相对优势越大（+682% → +780%）。 但在角度/水平控制上的劣势也更明显（PID胜出项从19→21）。 这清晰地展示了LADRC的"偏科"特性：ESO对可直接观测的扰动轴（垂直）效果显著，对耦合轴（水平）因b0不准反而恶化。

LADRC 在扰动场景的价值证据

1. 高度控制：扰动越强，优势越大
无扰动测试中LADRC高度优势+682%，扰动测试中扩大到+780%。ESO的z3成功估计了质量×2和推力-40%对垂直轴的复合影响。
2. EKF融合质量更高
LADRC的EKF高度test_ratio仅为PID的25%（0.03 vs 0.12），位置test_ratio也略优（0.05 vs 0.06）。 说明LADRC产生的运动轨迹更符合EKF的预测模型。
3. Pitch姿态跟踪略优
在强扰动中LADRC的pitch姿态误差15.8° vs PID的16.8°，微弱领先6%。这是少数LADRC在角度控制上不输PID的场景。

但也暴露了LADRC的脆弱点

1. b0失配的连锁反应
Roll/pitch的b0受SIH_MASS、SIH_T_MAX、SIH_L_ROLL等多个参数耦合影响。质量翻倍后b0减半(60→30)，推力降40%后b0再降(30→18)。固定b0=60远高于实际值，导致控制量不足、跟踪滞后。
2. 水平控制链崩溃
b0不准 → 角速率跟踪差 → 姿态偏差大 → 侧风下8m/s风速未被有效抵抗 → 19m漂移

结论与建议

扰动测试的发现

本次测试首次在扰动的SIH仿真中部分证明了LADRC的差异化价值：

  • 垂直轴Z：LADRC以780%碾压PID，这是ESO扰动补偿能力的直接证据
  • 水平轴X/Y：LADRC因b0不准而崩溃，角速率控制差导致19m漂移
  • 高度EKF质量：LADRC以254%优于PID，控制输出更平滑

LADRC的实际价值定位

如果把LADRC看作是"万能控制器"，期望它在所有轴上都超越精心调优的PID，那是不现实的。 LADRC的真正价值是：在对总扰动可准确建模的轴上（如推力轴Z），用少量参数实现接近甚至超越PID的性能，同时对参数变化更鲁棒。

改进方向

  1. 分轴b0辨识：对roll/pitch做阶跃响应实验确定准确的b0
  2. 在线b0估计：利用SIH_MASS等参数变化实时调整b0
  3. 混合控制策略：Z轴用LADRC（发挥ESO优势），X/Y轴用PID（保证角速率精度）
  4. 只保留Z轴LADRC：作为高度控制器的替代方案，这是当前最能体现实用价值的切入点
