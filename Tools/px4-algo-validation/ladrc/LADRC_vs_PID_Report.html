1. 执行摘要

本报告对比了 PX4 默认 PID 控制器 与新实现的 LADRC（线性自抗扰控制） 在相同 SITL 仿真环境下的飞行表现。LADRC 算法已成功集成到 mc_rate_control 模块中，通过参数 MC_LADRC_ENABLE 无缝切换，不影响原有 PID/INDI 算法。

核心结论：LADRC 算法已正确实现并编译通过，ESO 离散时间极点配置保证了数值稳定性。当前默认参数下 LADRC 的角速率跟踪精度（RMS 3.3 deg/s）远逊于 PID（0.09 deg/s），主要原因是 b0（控制效能）估计不准确和观测器/控制器带宽匹配不足。PID 在所有关键指标上全面领先（19/34 项胜出），但 LADRC 的框架基础已建立，通过系统性参数辨识可显著提升性能。

2. 算法概述

2.1 PID 控制器（PX4 默认）

PX4 的角速率 PID 控制器采用并行形式：

// PID 控制律 torque = K * (P * rate_error + I * integral + D * derivative) + FF * rate_sp // 默认参数 (SIH quadx) // Roll: P=0.15, I=0.2, D=0.003, K=1.0 // Pitch: P=0.15, I=0.2, D=0.003, K=1.0 // Yaw: P=0.2, I=0.1, D=0.0, K=1.0

2.2 LADRC 控制器（新实现）

LADRC 基于韩京清的自抗扰控制框架，核心是 扩张状态观测器（ESO），实时估计并补偿总扰动：

// 3阶 ESO：估计角速率(z1)、角加速度(z2)、总扰动(z3) // 离散时间极点配置：所有极点在 z = exp(-wo * dt) z1_pred = z1 + dt * z2 z2_pred = z2 + dt * (z3 + b0 * u_prev) z1 = z1_pred + l1 * (rate - z1_pred) z2 = z2_pred + l2 * (rate - z1_pred) z3 = z3 + l3 * (rate - z1_pred) // PD 控制律 + 扰动补偿 u0 = wc * (rate_sp - z1) u = (u0 - z3) / b0

2.3 关键设计决策

设计点方案原因
ESO 离散化精确极点配置 (exp(-wo*dt))前向欧拉在 wo*dt>0.5 时发散
ESO 初始化首帧 z1=当前角速率避免初始大误差导致 z3 爆炸
z3 限幅±200 rad/s²防止扰动估计发散
切换机制MC_LADRC_ENABLE 参数优先级 LADRC > INDI > PID

5. 问题分析与根因

5.1 ESO 离散化问题（已修复）

已修复：原始前向欧拉离散化在高观测器带宽下数值不稳定。wo=50 rad/s, dt=0.004s 时，beta2*dt=30 >> 1，导致 ESO 发散。改用精确 z 平面极点配置（p=exp(-wo*dt)）后，任意带宽下均保证稳定。

5.2 b0 参数辨识问题（主要问题）

b0（控制效能增益）是 LADRC 最关键的参数，表示单位归一化力矩产生的角加速度。理论计算值 b0=80（基于 SIH 惯性和最大力矩），但在实际飞行中：

  • 悬停时有效 b0 ≈ 40（一半电机功率用于推力，剩余用于力矩）
  • PID 等效 b0 ≈ 15-67（反推自 PID 增益和闭环带宽）
  • b0 偏大 → 控制器输出被过度缩小 → 无人机无法维持姿态
  • b0 偏小 → 控制器过度反应 → 振荡和饱和

5.3 观测器/控制器带宽匹配

LADRC 的性能高度依赖 wo/wc 比率。经验法则 wo ≈ 2-4×wc：

6. 改进建议

6.1 短期（参数调优）

  • b0 系统辨识：通过阶跃响应实验测量实际控制效能，而非理论计算
  • 渐进步进调参：从保守参数开始，逐步增加 wo 和 wc，观察稳定性边界
  • Yaw b0 独立标定：Yaw 轴的力矩常数为 Q_max=0.1 N·m，远低于 Roll/Pitch

6.2 中期（算法改进）

  • 加入前馈项：u = (wc*(rate_sp - z1) + b0*rate_sp_dot - z3) / b0，改善设定值跟踪
  • 变增益 ESO：根据飞行状态（悬停/机动）动态调整观测器增益
  • ESO 状态渐变启动：前 N 个周期渐增 l1, l2, l3，避免启动冲击

6.3 长期（功能扩展）

  • 自适应 b0：在线辨识控制效能，适应不同负载和电池状态
  • NLADRC（非线性 ESO）：fal 函数替代线性增益，兼顾跟踪速度和噪声抑制
  • 多模切换：根据飞行模式自动切换 LADRC/PID/INDI 参数集
