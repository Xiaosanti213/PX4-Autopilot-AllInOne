# 我们把自抗扰控制塞进了 PX4，然后在仿真里和 PID 打了一架

> 一场 LADRC vs PID 的正面硬刚，结果出人意料。

---

## 一、为什么是 LADRC？

提到无人机飞控，PID 是绝对的主角。从几百块的玩具四轴到几十万的行业无人机，PID 几乎一统天下。

但 PID 有几个"胎里带"的毛病：

1. **微分冲击** — 设定值跳变时，微分项(D)直接炸了
2. **积分副作用** — 消除静差的好帮手，也是积分饱和、超调、震荡的罪魁祸首
3. **线性组合局限** — P+I+D 就是误差的线性加权，遇到强非线性场景就力不从心
4. **耦合无解** — 多轴耦合、参数时变 → 必须重新调参

2003 年，美国克利夫兰州立大学的高志强教授在韩京清原始 ADRC 的基础上提出了**线性自抗扰控制 (LADRC)**。核心思想非常漂亮：

> 把所有不确定性——模型误差、外部扰动、轴间耦合、参数变化——打包成"总扰动"，用一个扩张状态观测器 (ESO) 实时估计，然后前馈补偿掉。

补偿掉之后，系统退化为一个纯积分器串联——控制律简化成一个 P（甚至不需 I 和 D）。

参数从 PID 的 9 个/轴（P/I/D × 3轴）减少到 **3 个/轴**（b0, wo, wc），调参工作量降低 70%。

听起来很美好。那问题来了——**在 PX4 仿真里，LADRC 到底能不能打？**

---

## 二、我们做了什么

### 2.1 把 LADRC 装进 PX4

我们在 PX4 的 `mc_rate_control` 模块里新增了两个文件：

- **`LADRC.hpp`** — 类定义，140 行
- **`LADRC.cpp`** — ESO + 控制律实现，160 行

核心改动只有约 300 行代码。原有的 PID 和 INDI 算法完全不受影响——通过一个参数 `MC_LADRC_ENABLE` 切换。

```
MC_LADRC_ENABLE = 0  →  PID (默认)
MC_LADRC_ENABLE = 1  →  LADRC
```

### 2.2 踩过的坑

**坑一：前向欧拉离散化 → 数值发散**

ESO 需要离散化才能跑在飞控上。最初我们用最简单的前向欧拉：

```cpp
z1 += dt * (z2 + beta1 * (rate - z1));  // ❌ 高带宽时发散
```

在 dt=4ms、wo=50rad/s 时，修正项 `beta1·dt = 3·50·0.004 = 0.6` 看起来还好，但 `beta2·dt = 3·2500·0.004 = 30` ——修正量是信号本身的 30 倍，直接炸了。

**解法**：改用 z 平面精确极点配置：

```cpp
const float p = expf(-wo * dt);         // 连续域极点映射到 z 平面
const float l1 = 3 * (1-p);             // 任意带宽下均稳定
const float l2 = 3 * (1-p)^2 / dt;
const float l3 = (1-p)^3 / dt^2;
```

**坑二：首帧初始化 → z3 爆炸**

上锁再解锁后，ESO 状态归零。如果无人机此时已在运动（比如刚从故障恢复），`z1=0` 但 `rate=2rad/s` → innovation 巨大 → z3 瞬间爆炸。

**解法**：首帧设置 `z1 = rate`，innovation = 0，自然启动。

### 2.3 测试方案

我们设计了两轮测试：

**第一轮：基线悬停（无扰动）**

|  | PID | LADRC |
|--|-----|-------|
| 飞行时长 | 70.9s | 71.6s |
| 参数 | 默认 PID | b0=40, wo=30, wc=15 |

**第二轮：多阶段扰动测试**

| 阶段 | 时长 | 注入扰动 |
|------|------|----------|
| 起飞 + 悬停 | 0~10s | 无 |
| 侧风攻击 | 10~20s | 8m/s 恒定侧风 |
| 载荷突增 | 20~35s | 质量 1.5kg → 3.0kg |
| 推力衰减 | 35~50s | 推力系数 ×0.6 (模拟电池亏电) |
| 恢复 | 50~60s | 所有扰动撤除 |
| 降落 | 60s+ | 无 |

两轮测试都通过 SIH (Simulation-In-Hardware) 运行，生成 ULG 日志后用 px4_ulg_analyzer 进行 34 项指标的全维度对比。

## 三、第一轮结果：干净的仿真里，PID 完胜

```
┌──────────────────────────────────────────┐
│              基线悬停对比                  │
│                                          │
│  PID  75 分 (C 级)  ████████████████     │
│  LADRC 60 分 (D 级)  ████████████         │
│                                          │
│  PID 胜出: 19/34 指标                     │
│  LADRC 胜出: 8/34 指标                    │
└──────────────────────────────────────────┘
```

**PID 碾压的维度：**

| 指标 | PID | LADRC | 差距 |
|------|-----|-------|------|
| roll 角速率 RMS | 0.09 deg/s | 3.30 deg/s | -97% |
| pitch 角速率 RMS | 0.04 deg/s | 3.49 deg/s | -99% |
| yaw 角速率 RMS | 0.02 deg/s | 0.73 deg/s | -97% |
| roll 姿态 RMS | 1.3° | 8.9° | -85% |
| 执行器饱和 | 0.0% | 19.4% | -100% |
| Gyro x 振动 P2P | 0.68 rad/s | 10.76 rad/s | -94% |

PID 在几乎所有角速率和姿态维度上都呈碾压态势。

**但 LADRC 有一个让人无法忽视的高光时刻：**

| 指标 | PID | LADRC | 差距 |
|------|-----|-------|------|
| **Z 轴高度 RMS** | 3.857m | **0.493m** | **+682%** |
| **3D 位置 RMS** | 3.860m | **0.888m** | **+334%** |
| **EKF 高度质量** | 0.14 | **0.09** | **+53%** |

在 Z 轴上，LADRC 把高度误差缩小到 PID 的 1/8。

这其实已经暴露了一个重要信号：**Z 轴（推力方向）的不确定性远大于 roll/pitch。** 重力、电池电压、推力非线性——这些都被 ESO 的 z3 一并估计并补偿了。

## 四、第二轮结果：加扰动后，差距反而拉大了

激动人心（又让人困惑）的结果：

```
┌──────────────────────────────────────────┐
│              多阶段扰动对比                │
│                                          │
│  PID  53 分 (F 级)  ████████████          │
│  LADRC 41 分 (F 级)  ████████             │
│                                          │
│  PID 胜出: 21/34 指标                     │
│  LADRC 胜出: 6/34 指标                    │
└──────────────────────────────────────────┘
```

等等——**为什么加了扰动之后，LADRC 不但没追上，反而差距从 15 分扩大到 12 分？**

这不是悖论。让我们看看各维度发生了什么：

| 指标 | PID (扰动) | LADRC (扰动) | 变化 |
|------|-----------|-------------|------|
| roll 角速率 | 0.09 | 3.08 | 与基线相近 |
| pitch 角速率 | 0.06 | 3.57 | 与基线相近 |
| yaw 角速率 | 0.03 | 2.05 | 与基线相近 |
| X 位置 RMS | 1.66m | **19.00m** | LADRC 大崩 |
| Y 位置 RMS | 0.21m | **1.34m** | LADRC 中度崩 |
| **Z 高度 RMS** | 3.63m | **0.41m** | **LADRC +780%！** |
| EKF 高度质量 | 0.12 | **0.03** | **LADRC +254%！** |

**规律非常明显：**

- **角速率跟踪**：LADRC 全面落后，且差距与扰动无关（都是 PID 好 97~99%）。这是 b0 失配的结构性缺陷。
- **位置跟踪 X/Y**：LADRC 在扰动时大幅退化（19m vs 1.7m）。因为角速率差 → 姿态差 → 水平位置失控。
- **高度跟踪 Z**：LADRC 优势反而**从 +682% 扩大到 +780%**。扰动越强，ESO 在 Z 轴的价值越大。

**这个结果揭示了一个残酷但清晰的真相：**

> LADRC 的 ESO 在 Z 轴（推力方向）大放异彩，但在 roll/pitch 轴上完全被 b0 不准拖垮。一个轴的极度优秀，救不了两个轴的集体拉胯。

## 五、深入分析：为什么 roll/pitch 的 LADRC 不行？

### 5.1 根因：b0 不准

LADRC 的扰动补偿公式是：

```
u = (u0 - z3) / b0
```

其中 `b0` 是"控制效能系数"，物理意义是"单位控制量产生多大加速度"。

在角速率控制中：
- b0 的理论值 ≈ 扭矩/(惯量·控制量)，取决于电机推力曲线、力臂长度、转动惯量
- PX4 SIH quadx 模型中，PID 反推的等效 b0 ≈ 15~67，且**因轴而异、随姿态变化**

但我们用了固定 b0=40。这导致：
- **roll/pitch 真实 b0 ≈ 15~25** → b0 被高估 60~170% → z3 低估实际扰动 → 控制量不足 → 跟踪差
- **yaw 真实 b0 ≈ 60~70** → b0 被低估 40% → z3 高估扰动 → z2/z3 震荡

### 5.2 ESO 的"双刃剑"效应

ESO 估计的是 `b0·u + disturbance`。如果 b0 的估计值和真实值差了 2 倍：

```
真实系统:    accel = 20·u + disturbance
ESO 认为:    accel = 40·u + disturbance_estimated

当 u=0.5:    真实 accel = 10, ESO pred = 20
            → innovation = -10 → z3 跑偏 → "补偿"变成"注入"
```

**在"干净"环境中，这导致性能退化。在"扰动"环境中，因为 roll/pitch 角速率影响水平位置，退化被级联放大——最终把 LADRC 在 Z 轴的优势也掩盖了。**

## 六、如果能来第二回合

基于两轮测试的数据，如果重来一次，我们有几个明确的改进方向：

### 6.1 系统辨识 b0（最高优先级）

```
方法：阶跃响应实验
1. roll 轴给 0.5 的阶跃力矩 (地面测试)
2. 记录角加速度响应
3. b0_roll = Δaccel / Δu
4. 对 pitch/yaw 重复
5. 拟合 b0 随姿态/电机转速的变化曲线
```

有了准确的 b0，ESO 才不是"盲人摸象"。

### 6.2 混合控制（最务实的方向）

```
Z 轴 (推力):  LADRC  ← ESO 天然适应推力非线性
Roll/Pitch:  PID    ← 简单的线性动力学，PID 足够好
Yaw:         PID    ← 同上

切换方式：MC_LADRC_ENABLE = 2 (混合模式)
```

不需要在所有轴上打败 PID，只需要在 Z 轴上发挥 LADRC 的独特优势。

### 6.3 改进 ESO

- **前馈项** — 在 ESO 预测模型中加入重力补偿和已知空气阻力
- **变增益 ESO** — 根据饱和状态动态降低 wo（饱和时降低观测器带宽，防止 windup）
- **渐变启动** — soft-start 模拟，避免首帧初始化冲击

## 七、总结：LADRC 是一把手术刀，不是瑞士军刀

| 问题 | 答案 |
|------|------|
| LADRC 能替代 PID 吗？ | **不能。** PID 在理想条件下就是近似最优解 |
| 那 LADRC 的价值在哪里？ | **应对不确定性。** 当系统偏离标称工况时（载荷变化、电池衰减、推力非线性），LADRC 的 ESO 自动补偿 |
| 在仿真里证明了吗？ | **部分证明。** Z 轴 +780% 的高度优势证明了 ESO 在推力方向的巨大价值 |
| 为什么整体评分更低？ | **b0 不准导致 roll/pitch 崩溃。** 一个轴的优秀无法弥补两个轴的拉胯 |
| 最值得推进的方向？ | **混合控制。** Z 轴 LADRC + Roll/Pitch PID，各取所长 |

### 一个比喻

> PID 是一辆 F1 赛车——在已知赛道上无人能敌。LADRC 是一辆越野车——在坑坑洼洼的野外（不确定性）能碾压 F1。但如果你在 F1 赛道上测试越野车，结果就是我们现在看到的这样。
